
## 三问决策树

三个判别维度正好对应模型的三个本质差异：**是否复合 → 是否可量化 → 数字/非数字各自的二分**。

**Q1：这个目标需要拆成几个可以分别完成的子目标/阶段来跟踪吗？**
（例：“办婚礼”= 订场地、发请柬、拍婚纱照……）
- 是 → **里程碑/项目型（Milestone）**（之后对每个子项再递归问 Q2～Q3）
- 否 → Q2

**Q2：目标的进展能用一个数字来衡量吗？**
（金额、公里数、页数、体重、分数……）
- 能 → Q3A
- 不能 → Q3B

**Q3A：这个数字是“从 0 累积到一个总量”，还是“把某个指标从现在的 A 变到 B”？**
- 累积到总量（存够 5 万、跑够 1000 km、读完 20 本）：每次记的是“又增加了多少”，总量随投入增长 → **累积型（Accumulation）**
- 指标从 A 到 B（体重 70→65、体脂率、排名、血压）：每次记的是“现在是多少”，读数会上下波动、会回退 → **指标型（Metric）**

**Q3B：这件事是“做完就算达成”，还是“持续推进、由你自己判断完成了几成”？**
- 有明确完成时点，做完即打钩（考到驾照、搬完家、报名比赛）→ **完成型（Binary）**
- 没有客观完成标准，靠写动态 + 主观评估进度（改善关系、提升品味、找到方向）→ **主观型（Subjective）**
