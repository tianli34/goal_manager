## 目标表单「期限」输入方式

需求经两轮澄清后定案：用户指出「期限」是时间跨度（区间/过程，如"三个月"），与「截止日期」（时间点）**并非同义词**，原需求「同义选项」的前提不成立。最终按「时长输入」实现，数据模型不变（`Goal.dueDate` 仍是唯一真值）。

实现要点：
- `core/enums.dart` 新增 `DueFieldMode{duration, deadline}`，`parse` 缺失/非法一律回落 `duration`（默认期限，含旧备份）。
- `core/date_utils.dart` 新增 `DurationUnit{day,week,month,year}`、`addCalendarDuration`（自然月推进 + 月末夹紧）、`inferCalendarDuration`（把已有 dueDate 反推为等价时长，保证往返不丢数据）、`sameDay`。
- `models/settings.dart` 增加 `dueFieldMode` 持久化；`ui/settings/settings_page.dart` 新增「目标表单」区（ListTile + radio 图标，避开新版 RadioListTile 废弃 API）。
- `ui/goals/goal_editor_page.dart`：按偏好切换 `期限`（数字+单位下拉）/`截止日期`（日期选择器）；`dueDate = 开始日期 + 时长`，无开始日期时以今天为锚点；时长模式改为上下排列避免窄屏挤压；编辑时反推时长回填，逾期等无法用正时长表示的情况临时退回日期选择；`data/repository.dart` 的配置变更记录文案跟随偏好。
- 作用范围决策：偏好只影响**表单输入方式**与配置变更记录；详情页、卡片、`remainingText`、导出等只读视图仍用「截止日期」描述持久化的日期值。

## 第二轮修正：期限只认开始日期，且规则要持久化

用户指出「期限 3 个月 + 未设置开始日期」时**不能从今天兜底**，锚点只能是开始日期。经一轮确认，用户选择「保留时长规则」（推翻上一轮「数据模型不变」的约定）：

- `models/goal.dart` 新增可选 `durationAmount` / `durationUnit`（`DurationUnit.parse` 见 `core/date_utils.dart`），以及 `durationRule` / `durationLabel` 派生 getter；JSON 往返兼容旧备份（字段缺失即无规则，非法单位回落「个月」）。
- 语义：`dueDate` 在有规则时是**派生值** = `startDate + 时长`；`startDate` 为空则 `dueDate` 为空，规则仍保存。切到「截止日期」模式保存时会清除规则。
- `data/repository.dart` 新增 `_applyDurationRule`，在 `_ensureStartDate`（创建、定时启动、状态变更、重新打开、里程碑激活）、`updateGoal`、`_sanitize`（导入恢复）统一生效，避免规则与日期脱节。
- 编辑器移除今天的兜底锚点；无开始日期时提示「3 个月，从开始日期起算；未设置开始日期，暂不计算结束日期，规则会随目标保存。」；编辑回填优先用规则，旧数据无规则时才从 `startDate → dueDate` 反推；补上开始日期可自动恢复时长输入。
- 详情页 / 卡片 / Markdown 导出在 `dueDate` 为空但有规则时显示「期限 3 个月 · 待开始日期」等说明；设置项说明同步。
- `docs/screenshots/` 四张图重截：01 无开始日期、04 有开始日期（显示结束于 2027-02-04）、02 截止日期对照、03 设置页。

验证：`flutter analyze` 无问题、`dart format` 全量一致、`flutter test` 49 项全过。

## 键盘弹出时隐藏悬浮主页按钮

- 需求：键盘弹起时 Scaffold 会把 `HomeFloatingButton` 顶到键盘上方，挡住输入框/表单按钮。
- 实现只改 `lib/ui/home.dart` 的 `shouldShowHomeButton()`：追加 `MediaQuery.viewInsetsOf(context).bottom == 0` 条件。该方法是目标详情、目标编辑、复盘编辑三页显示主页 FAB 的唯一入口，且三页同时用它决定 ListView 底部留白（104→36/32），因此隐藏按钮时多余留白同步消失，无需逐页改动。
- `HomeFloatingButton` 保持纯渲染组件，不自行判断键盘；后续若有页面绕过 `shouldShowHomeButton` 直接使用，需另做处理。
- `test/home_button_test.dart` 新增组件测试：用 `tester.view.viewInsets = const FakeViewPadding(bottom: 320)` 模拟键盘，验证隐藏；复位 `FakeViewPadding.zero` 后验证恢复。
- 验证：`flutter analyze` 无问题、`dart format` 46 文件 0 改动、`flutter test` 50 项全过。本机仍需设置 `NO_PROXY` 才能让 flutter_tester 连上本地 WebSocket（仅设 NO_PROXY/no_proxy 就够，不必清空所有代理变量）。
